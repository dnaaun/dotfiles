# jj sparse list

List the patterns that are currently present in the working copy.

By default, a newly cloned or initialized repo will have a pattern matching all files from the repo root. That pattern is rendered as `.` (a single period).

## Usage

```
jj sparse list [OPTIONS]
```

## Options

```
-h, --help    Print help
```
