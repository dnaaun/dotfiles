# jj gerrit

Interact with Gerrit Code Review.

## Usage

```
jj gerrit [OPTIONS] <COMMAND>
```

## Commands

- [upload](./gerrit/upload.md) - Upload changes to Gerrit for code review, or update existing changes

## Options

```
-h, --help    Print help
```
