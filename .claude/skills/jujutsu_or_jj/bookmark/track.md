# jj bookmark track

Start tracking given remote bookmarks.

## Usage

```
jj bookmark track [OPTIONS] <NAMES@REMOTE>...
```

## Arguments

- `<NAMES@REMOTE>...` - Remote bookmarks to track (format: bookmark@remote)

## Options

```
-h, --help    Print help
```
