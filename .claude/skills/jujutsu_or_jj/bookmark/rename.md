# jj bookmark rename

Rename `old` bookmark name to `new` bookmark name.

## Usage

```
jj bookmark rename [OPTIONS] <OLD> <NEW>
```

## Arguments

- `<OLD>` - The old name of the bookmark
- `<NEW>` - The new name of the bookmark

## Options

```
-h, --help    Print help
```
