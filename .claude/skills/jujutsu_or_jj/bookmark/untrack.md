# jj bookmark untrack

Stop tracking given remote bookmarks.

## Usage

```
jj bookmark untrack [OPTIONS] <NAMES@REMOTE>...
```

## Arguments

- `<NAMES@REMOTE>...` - Remote bookmarks to untrack (format: bookmark@remote)

## Options

```
-h, --help    Print help
```
