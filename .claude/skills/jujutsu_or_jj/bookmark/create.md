# jj bookmark create

Create a new bookmark.

## Usage

```
jj bookmark create [OPTIONS] <NAMES>...
```

## Arguments

- `<NAMES>...` - The bookmarks to create

## Options

```
-r, --revision <REVSET>   The bookmark's target revision [default: @] [aliases: --to]

-h, --help                Print help
```
