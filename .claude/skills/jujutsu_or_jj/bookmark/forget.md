# jj bookmark forget

Forget a bookmark without marking it as a deletion to be pushed.

## Usage

```
jj bookmark forget [OPTIONS] <NAMES>...
```

## Arguments

- `<NAMES>...` - The bookmarks to forget. By default matches exactly. Use `glob:` prefix for wildcards.

## Options

```
-h, --help    Print help
```
