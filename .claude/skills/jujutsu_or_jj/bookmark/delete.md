# jj bookmark delete

Delete an existing bookmark and propagate the deletion to remotes on the next push.

## Usage

```
jj bookmark delete [OPTIONS] <NAMES>...
```

## Arguments

- `<NAMES>...` - The bookmarks to delete. By default matches exactly. Use `glob:` prefix for wildcards.

## Options

```
-h, --help    Print help
```
