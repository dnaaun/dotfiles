# jj git

Commands for working with Git remotes and the underlying Git repo.

See this comparison: https://jj-vcs.github.io/jj/latest/git-comparison/
Table of commands: https://jj-vcs.github.io/jj/latest/git-command-table

## Usage

```
jj git [OPTIONS] <COMMAND>
```

## Commands

- [clone](./git/clone.md) - Create a new repo backed by a clone of a Git repo
- [export](./git/export.md) - Update the underlying Git repo with changes made in the repo
- [fetch](./git/fetch.md) - Fetch from a Git remote
- [import](./git/import.md) - Update repo with changes made in the underlying Git repo
- [init](./git/init.md) - Create a new Git backed repo
- [push](./git/push.md) - Push to a Git remote
- [remote](./git/remote.md) - Manage Git remotes
- [root](./git/root.md) - Show the underlying Git directory

## Options

```
-h, --help    Print help
```
