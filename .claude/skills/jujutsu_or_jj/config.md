# jj config

Manage config options.

Operates on jj configuration, which comes from the config file and environment variables.

See: https://jj-vcs.github.io/jj/latest/config/

## Usage

```
jj config [OPTIONS] <COMMAND>
```

## Commands

- [edit](./config/edit.md) - Start an editor on a jj config file [alias: e]
- [get](./config/get.md) - Get the value of a given config option [alias: g]
- [list](./config/list.md) - List variables set in config files [alias: l]
- [path](./config/path.md) - Print the paths to the config files [alias: p]
- [set](./config/set.md) - Update a config file to set the given option [alias: s]
- [unset](./config/unset.md) - Update a config file to unset the given option [alias: u]

## Options

```
-h, --help    Print help
```
