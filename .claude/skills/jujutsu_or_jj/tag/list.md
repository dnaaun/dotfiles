# jj tag list

List tags.

## Usage

```
jj tag list [OPTIONS] [NAMES]...
```

## Arguments

- `[NAMES]...` - Show tags whose names match the given patterns

## Options

```
-T, --template <TEMPLATE>   Render each tag using the given template

-h, --help                  Print help
```
