# jj edit

Sets the specified revision as the working-copy revision.

Note: it is generally recommended to instead use `jj new` and `jj squash`.

See: https://jj-vcs.github.io/jj/latest/FAQ#how-do-i-resume-working-on-an-existing-change

## Usage

```
jj edit [OPTIONS] <REVSET>
```

## Arguments

- `<REVSET>` - The commit to edit

## Options

```
-h, --help    Print help
```
