# jj sparse

Manage which paths from the working-copy commit are present in the working copy.

## Usage

```
jj sparse [OPTIONS] <COMMAND>
```

## Commands

- [edit](./sparse/edit.md) - Start an editor to update the patterns
- [list](./sparse/list.md) - List the patterns that are currently present
- [reset](./sparse/reset.md) - Reset the patterns to include all files
- [set](./sparse/set.md) - Update the patterns that are present

## Options

```
-h, --help    Print help
```
