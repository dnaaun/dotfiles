# jj util

Infrequently used commands such as for generating shell completions.

## Usage

```
jj util [OPTIONS] <COMMAND>
```

## Commands

- [completion](./util/completion.md) - Print a command-line-completion script
- [config-schema](./util/config-schema.md) - Print the JSON schema for the jj TOML config format
- [exec](./util/exec.md) - Execute an external command via jj
- [gc](./util/gc.md) - Run backend-dependent garbage collection
- [install-man-pages](./util/install-man-pages.md) - Install Jujutsu's manpages to the provided path
- [markdown-help](./util/markdown-help.md) - Print the CLI help for all subcommands in Markdown

## Options

```
-h, --help    Print help
```
