# jj bookmark

Manage bookmarks.

See: https://jj-vcs.github.io/jj/latest/bookmarks

## Usage

```
jj bookmark [OPTIONS] <COMMAND>
```

## Commands

- [create](./bookmark/create.md) - Create a new bookmark [alias: c]
- [delete](./bookmark/delete.md) - Delete an existing bookmark [alias: d]
- [forget](./bookmark/forget.md) - Forget a bookmark without marking it as a deletion [alias: f]
- [list](./bookmark/list.md) - List bookmarks and their targets [alias: l]
- [move](./bookmark/move.md) - Move existing bookmarks to target revision [alias: m]
- [rename](./bookmark/rename.md) - Rename a bookmark [alias: r]
- [set](./bookmark/set.md) - Create or update a bookmark to point to a certain commit [alias: s]
- [track](./bookmark/track.md) - Start tracking given remote bookmarks [alias: t]
- [untrack](./bookmark/untrack.md) - Stop tracking given remote bookmarks

## Options

```
-h, --help    Print help
```
