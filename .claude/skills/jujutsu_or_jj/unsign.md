# jj unsign

Drop a cryptographic signature.

See also: https://jj-vcs.github.io/jj/latest/config/#commit-signing

## Usage

```
jj unsign [OPTIONS]
```

## Options

```
-r, --revisions <REVSETS>   What revision(s) to unsign

-h, --help                  Print help
```
