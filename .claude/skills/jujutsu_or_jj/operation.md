# jj operation

Commands for working with the operation log.

See: https://jj-vcs.github.io/jj/latest/operation-log/

## Usage

```
jj operation [OPTIONS] <COMMAND>
```

## Commands

- [abandon](./operation/abandon.md) - Abandon operation history
- [diff](./operation/diff.md) - Compare changes to the repository between two operations
- [log](./operation/log.md) - Show the operation log
- [restore](./operation/restore.md) - Create a new operation that restores the repo to an earlier state
- [revert](./operation/revert.md) - Create a new operation that reverts an earlier operation
- [show](./operation/show.md) - Show changes to the repository in an operation

## Options

```
-h, --help    Print help
```
