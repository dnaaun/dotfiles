# jj file untrack

Stop tracking specified paths in the working copy.

## Usage

```
jj file untrack [OPTIONS] <FILESETS>...
```

## Arguments

- `<FILESETS>...` - Paths to untrack. They must already be ignored (via .gitignore or .git/info/exclude in colocated repos).

## Options

```
-h, --help    Print help
```
