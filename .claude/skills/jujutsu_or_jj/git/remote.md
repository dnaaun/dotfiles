# jj git remote

Manage Git remotes.

The Git repo will be a bare git repo stored inside the `.jj/` directory.

## Usage

```
jj git remote [OPTIONS] <COMMAND>
```

## Commands

- [add](./remote/add.md) - Add a Git remote
- [list](./remote/list.md) - List Git remotes
- [remove](./remote/remove.md) - Remove a Git remote and forget its bookmarks
- [rename](./remote/rename.md) - Rename a Git remote
- [set-url](./remote/set-url.md) - Set the URL of a Git remote

## Options

```
-h, --help    Print help
```
