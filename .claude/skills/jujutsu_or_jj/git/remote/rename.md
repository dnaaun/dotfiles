# jj git remote rename

Rename a Git remote.

## Usage

```
jj git remote rename [OPTIONS] <OLD> <NEW>
```

## Arguments

- `<OLD>` - The name of an existing remote
- `<NEW>` - The desired name for `old`

## Options

```
-h, --help    Print help
```
