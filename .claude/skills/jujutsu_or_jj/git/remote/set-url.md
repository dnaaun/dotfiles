# jj git remote set-url

Set the URL of a Git remote.

## Usage

```
jj git remote set-url [OPTIONS] <REMOTE> <URL>
```

## Arguments

- `<REMOTE>` - The remote's name
- `<URL>` - The desired URL or path. Local path will be resolved to absolute form.

## Options

```
-h, --help    Print help
```
