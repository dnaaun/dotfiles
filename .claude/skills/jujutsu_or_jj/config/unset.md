# jj config unset

Update a config file to unset the given option.

## Usage

```
jj config unset [OPTIONS] <--user|--repo> <NAME>
```

## Arguments

- `<NAME>` - The config option name

## Options

```
--user    Target the user-level config
--repo    Target the repo-level config
-h, --help    Print help
```
