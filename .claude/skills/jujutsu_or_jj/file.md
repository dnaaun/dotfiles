# jj file

File operations.

## Usage

```
jj file [OPTIONS] <COMMAND>
```

## Commands

- [annotate](./file/annotate.md) - Show the source change for each line of the target file
- [chmod](./file/chmod.md) - Sets or removes the executable bit for paths
- [list](./file/list.md) - List files in a revision
- [show](./file/show.md) - Print contents of files in a revision
- [track](./file/track.md) - Start tracking specified paths in the working copy
- [untrack](./file/untrack.md) - Stop tracking specified paths in the working copy

## Options

```
-h, --help    Print help
```
