# jj util install-man-pages

Install Jujutsu's manpages to the provided path.

## Usage

```
jj util install-man-pages [OPTIONS] <PATH>
```

## Arguments

- `<PATH>` - The path where manpages will be installed. An example path might be `/usr/share/man`. The provided path will be appended with `man1`, etc., as appropriate.

## Options

```
-h, --help    Print help
```
